# 2단계: API 연결

## 1. 목적

네이버 뉴스 검색 API에 안전하게 연결되는지 확인한다.

이번 단계에서는 많은 데이터를 수집하지 않는다.
검색어 `전기차`로 뉴스 검색 결과 10건만 요청하고,
응답 상태 코드와 데이터 구조를 확인한다.

## 2. 쉬운 개념 설명

API는 프로그램이 다른 서비스에 정해진 방식으로 요청을 보내고 데이터를 받는 통로다.

이번 프로젝트에서는 네이버 뉴스 검색 API에 다음 정보를 보낸다.

- 검색어: 전기차
- 결과 개수: 10건
- 정렬 방식: 날짜순

네이버 API는 사용자를 확인하기 위해 `Client ID`와 `Client Secret`을 요구한다.
이 값은 비밀번호와 비슷하게 다뤄야 하므로 코드에 직접 적지 않는다.

## 3. 사용자가 먼저 생각할 질문

1. 네이버 개발자 센터에서 애플리케이션을 등록했는가?
2. 등록한 애플리케이션에서 검색 API 사용 권한을 선택했는가?
3. `.env` 파일을 Git에 올리지 않도록 관리할 준비가 되었는가?

## 4. 최소 실행 코드

먼저 프로젝트 루트에 `.env` 파일을 만든다.

```text
NAVER_CLIENT_ID=발급받은_클라이언트_ID
NAVER_CLIENT_SECRET=발급받은_클라이언트_SECRET
```

실제 키 값은 채팅, README, 노트북, Git에 저장하지 않는다.

그다음 아래 명령을 실행한다.

```powershell
uv run python src/check_naver_api.py
```

## 5. 결과 해석 방법

정상 연결이면 다음과 비슷한 정보가 출력된다.

```text
API 연결 확인 결과
상태 코드: 200
전체 검색 결과 수(total): ...
요청 시작 위치(start): 1
응답 기사 수(display): 10
items 타입: list
items 개수: 10
```

첫 번째 기사 데이터 구조에는 보통 다음 필드가 포함된다.

- title
- originallink
- link
- description
- pubDate

`title`과 `description`에는 검색어가 `<b>` 태그로 감싸져 있을 수 있다.
이 HTML 태그 제거는 4단계 전처리에서 다룬다.

## 6. 오류, 편향, 데이터 누수 가능성

`환경변수 설정 오류`가 나오면 `.env` 파일이 없거나 변수 이름이 잘못된 것이다.

`상태 코드: 403`이 나오면 네이버 개발자 센터에서 애플리케이션의 검색 API 권한이 빠졌을 가능성이 있다.

`상태 코드: 400`이 나오면 요청 파라미터가 잘못됐을 가능성이 있다.

이번 단계는 연결 확인이 목적이므로 결과 10건을 보고 라벨 기준이나 모델 성능을 판단하면 안 된다.
10건은 전체 전기차 뉴스 흐름을 대표하지 않는다.

## 7. 완료 조건

2단계는 다음 조건을 만족하면 완료된다.

- `.env.example`에는 변수 이름만 있다.
- `.env`는 `.gitignore`에 포함되어 있다.
- 실제 API 키가 코드와 문서에 저장되어 있지 않다.
- `uv run python src/check_naver_api.py` 실행 시 상태 코드와 `items` 구조를 확인할 수 있다.
- 처음 API 호출은 검색 결과 10건만 요청한다.

## 8. 실행 확인 결과

사용자가 2026년 8월 3일에 실행한 결과, API 연결이 정상으로 확인되었다.

- 상태 코드: 200
- 검색어: 전기차
- 응답 기사 수: 10
- items 타입: list
- 첫 번째 기사 필드: title, originallink, link, description, pubDate

따라서 2단계 API 연결은 완료된 것으로 본다.
