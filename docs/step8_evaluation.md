# 8단계: 평가

## 1. 목적

키워드 기준 모델, Qwen 로컬 모델, GPT API 모델의 분류 결과를 같은 기준으로 비교한다.

이번 평가는 최종 테스트용 데이터를 사용하지 않고,
개발용(dev) 데이터만 사용한다.

## 2. 쉬운 개념 설명

Accuracy는 전체 중 몇 개를 맞혔는지 보는 지표다.

하지만 라벨 개수가 한쪽으로 치우쳐 있으면 Accuracy만으로는 부족하다.
이번 dev 데이터는 긍정이 많고 중립과 부정이 적기 때문에,
각 라벨을 균형 있게 보는 Macro-F1을 함께 확인한다.

## 3. 사용자가 먼저 생각할 질문

1. 모델이 많이 맞힌 라벨과 거의 못 맞힌 라벨이 무엇인가?
2. 중립을 긍정이나 부정으로 잘못 판단하는가, 아니면 긍정·부정을 중립으로 너무 보수적으로 판단하는가?
3. 평가 결과를 보고 최종 테스트 데이터를 열어보고 싶은 유혹을 피할 수 있는가?

## 4. 최소 실행 코드

이미 각 모델 스크립트 실행 시 평가 리포트가 생성된다.

```powershell
uv run python src/rule_based_baseline.py
uv run python src/qwen_local_classifier.py --split dev --limit 0 --allow-omp-duplicate
uv run python src/openai_gpt_classifier.py --run --split dev --limit 0 --max-krw 10000
```

## 5. 모델별 평가 결과

평가 범위는 모두 dev 데이터다.

| 모델 | 평가 기사 수 | 분류 실패 수 | Accuracy | Macro-F1 |
| --- | ---: | ---: | ---: | ---: |
| 키워드 규칙 기준 모델 | 28 | 0 | 0.429 | 0.263 |
| Qwen 로컬 모델 | 24 | 4 | 0.292 | 0.381 |
| GPT API 모델 | 28 | 0 | 0.643 | 0.653 |

## 6. GPT API 평가 결과

GPT API 모델은 dev 28건 전체를 분류했고, 실패한 1건은 rate limit 재시도로 보완했다.

- 모델: `gpt-5.6-luna`
- 분류 실패 수: 0
- Accuracy: 0.643
- Macro-F1: 0.653
- 예측 파일 누적 추정 비용: 약 8.3265원

클래스별 지표는 다음과 같다.

| 라벨 | Precision | Recall | F1 |
| --- | ---: | ---: | ---: |
| 긍정 | 1.000 | 0.571 | 0.727 |
| 중립 | 0.231 | 1.000 | 0.375 |
| 부정 | 1.000 | 0.750 | 0.857 |

혼동행렬은 다음과 같다.

| 실제 \ 예측 | 긍정 | 중립 | 부정 |
| --- | ---: | ---: | ---: |
| 긍정 | 12 | 9 | 0 |
| 중립 | 0 | 3 | 0 |
| 부정 | 0 | 1 | 3 |

## 7. 결과 해석 방법

GPT API 모델이 세 모델 중 가장 높은 Accuracy와 Macro-F1을 보였다.

다만 GPT API 모델은 긍정 뉴스를 중립으로 많이 판단했다.
이는 “국내 시장 전체 영향이 명확하지 않으면 중립”이라는 기준을 엄격하게 적용했기 때문이다.

Qwen 로컬 모델도 중립 예측에 치우쳤고, JSON 출력 형식이 안정적이지 않아 분류 실패가 있었다.

키워드 기준 모델은 단어만 보고 판단하기 때문에 문맥을 잘못 해석했다.
예를 들어 안전 대응 강화 뉴스도 `화재`라는 단어 때문에 부정으로 볼 수 있다.

## 8. 오류, 편향, 데이터 누수 가능성

dev 데이터는 긍정 21건, 중립 3건, 부정 4건으로 긍정에 치우쳐 있다.
따라서 현재 수치만으로 최종 성능을 단정하면 안 된다.

최종 테스트 데이터는 아직 평가에 사용하지 않았다.
프롬프트나 라벨 가이드를 수정할 때 최종 테스트 데이터를 보면 데이터 누수가 생긴다.

GPT API가 중립을 많이 선택한 사례는 라벨 가이드의 경계 사례를 다시 검토할 때 사용할 수 있다.
단, 이 검토는 dev 데이터만 기준으로 한다.

## 9. 완료 조건

8단계는 다음 조건을 만족하면 완료된다.

- Accuracy 외에 Macro-F1을 확인했다.
- 클래스별 Precision, Recall, F1을 확인했다.
- 혼동행렬을 확인했다.
- 분류 실패 수를 확인했다.
- 중립 오판 경향을 확인했다.
- 최종 테스트 데이터는 아직 사용하지 않았다.
