ㅋ# 3단계: 데이터 수집 계획

## 1. 목적

네이버 뉴스 검색 API로 어떤 검색어를 사용해 데이터를 수집할지 정한다.

이번 단계에서는 바로 많은 데이터를 수집하지 않는다.
먼저 검색어별 10건씩만 수집해 데이터 모양을 확인한다.

## 2. 쉬운 개념 설명

뉴스 검색 API는 검색어에 따라 가져오는 뉴스가 크게 달라진다.

예를 들어 `전기차`만 검색하면 넓은 주제의 뉴스가 모이지만,
`배터리 화재`를 검색하면 부정적인 뉴스가 많이 모일 가능성이 있다.

그래서 검색어는 긍정, 중립, 부정 이슈가 한쪽으로 치우치지 않도록 구성해야 한다.

## 3. 검색어 후보

초기 검색어 후보는 다음과 같이 둔다.

- 전기차
- 전기차 보조금
- 전기차 판매
- 전기차 충전
- 배터리 화재
- 전기차 가격

각 검색어의 역할은 다음과 같다.

| 검색어 | 기대되는 뉴스 성격 | 주의할 점 |
| --- | --- | --- |
| 전기차 | 전체 시장 뉴스 | 범위가 넓어 관련성이 낮은 뉴스가 섞일 수 있음 |
| 전기차 보조금 | 정책, 구매 비용 | 확대와 축소 뉴스가 모두 섞일 수 있음 |
| 전기차 판매 | 수요, 시장 흐름 | 특정 기업 실적 기사에 치우칠 수 있음 |
| 전기차 충전 | 인프라, 이용 편의 | 충전소 확대와 충전 불편 뉴스가 섞일 수 있음 |
| 배터리 화재 | 안전, 소비자 신뢰 | 부정 뉴스 비중이 높아질 수 있음 |
| 전기차 가격 | 구매 장벽, 가격 경쟁 | 가격 인하와 가격 부담 뉴스가 섞일 수 있음 |

## 4. 수집 기준 초안

초기 수집 기준은 다음과 같이 확정한다.

- API: 네이버 뉴스 검색 API
- 언어: 한국어 뉴스
- 시장 기준: 국내 전기차 시장
- 정렬 방식: 날짜순
- 검색어별 최초 수집량: 10건
- 저장 형식: CSV
- 저장 항목: 검색어, 수집일, 제목, 요약문, 원문 링크, 네이버 링크, 발행일
- 원본 데이터와 전처리 데이터는 별도로 저장

처음에는 검색어별 10건씩만 수집해 데이터 모양을 확인한 뒤,
문제가 없을 때 수집량을 늘리는 방식이 안전하다.

## 5. 최소 실행 코드

아래 명령으로 검색어별 10건씩 수집한다.

```powershell
uv run python src/collect_news_sample.py
```

수집 결과는 `data/raw/` 폴더에 저장된다.

- 검색어별 원본 JSON 파일
- 전체 샘플 CSV 파일

같은 날짜에 같은 검색어의 원본 JSON 파일이 이미 있으면 API를 다시 호출하지 않고
저장된 파일을 읽는다.

## 6. 사용자가 먼저 생각할 질문

1. 위 검색어 6개로 시작해도 되는가?
2. 검색어별 최초 수집량은 10건으로 테스트한 뒤 100건으로 늘려도 되는가?
3. 최근 뉴스 중심으로 날짜순 수집을 먼저 진행해도 되는가?

위 질문은 다음과 같이 확정했다.

- 검색어 6개로 시작한다.
- 검색어별 10건씩 먼저 테스트 수집한다.
- 정렬은 날짜순으로 진행한다.

## 7. 결과 해석 방법

검색어별로 수집된 뉴스 수와 제목 예시를 확인한다.

특정 검색어에서 관련 없는 뉴스가 많으면 검색어를 더 구체적으로 바꾼다.
특정 검색어에서 한쪽 라벨만 지나치게 많이 나오면 검색어 구성을 조정한다.

## 8. 오류, 편향, 데이터 누수 가능성

검색어 선택 자체가 데이터 편향을 만들 수 있다.

예를 들어 `배터리 화재` 검색어를 많이 넣으면 부정 뉴스가 과도하게 많아질 수 있다.
반대로 `보조금 확대` 같은 검색어만 쓰면 긍정 뉴스가 과도하게 많아질 수 있다.

같은 뉴스가 여러 검색어에서 중복 수집될 수 있다.
나중에 원문 링크 기준으로 중복 제거가 필요하다.

네이버 뉴스 검색 API는 검색 결과 API이므로 전체 뉴스 데이터베이스를 완전하게 제공하는 것이 아니다.
따라서 수집 결과를 국내 전기차 시장 전체 여론이라고 과도하게 해석하면 안 된다.

## 9. 완료 조건

3단계는 다음 조건을 만족하면 완료된다.

- 검색어 후보가 정해져 있다.
- 검색어별 수집량 초안이 정해져 있다.
- 정렬 방식이 정해져 있다.
- 수집일과 검색어를 함께 저장하기로 정해져 있다.
- 원본 데이터와 전처리 데이터를 분리하기로 정해져 있다.
- 검색어별 10건씩 샘플 수집 결과를 확인한다.
