# 9단계: 오류 분석과 프롬프트 개선

## 1. 목적

GPT API 모델의 오분류 사례를 검토하고, 그 결과를 바탕으로 프롬프트를 반복 개선한다.

이번 단계에서는 dev 데이터만 사용한다.
최종 테스트 데이터는 프롬프트 수정에 사용하지 않는다.

> **현재 상태 안내:** 아래 성능과 오류 분석은 `gold_label` 재검토 전 초기 실험 기록이다.
> 이후 35건의 `gold_label` 재검토를 완료했으므로 기록된 수치를 현재 성능으로 해석하지 않으며,
> 새 평가 데이터를 구성한 뒤 다시 평가할 예정이다.
> 당시 final_test는 블라인드 데이터로 설계했지만 이미 수동 검토했으므로 최종 블라인드 테스트로 사용하지 않는다.

## 2. 쉬운 개념 설명

모델이 틀린 사례를 보면 왜 틀렸는지 알 수 있다.

예를 들어 사람이 `긍정`으로 라벨링한 뉴스를 GPT가 `중립`으로 분류했다면,
모델이 시장 개선 효과를 너무 엄격하게 본 것일 수 있다.

반대로 사람이 `중립`으로 라벨링한 뉴스를 GPT가 `긍정`으로 분류했다면,
모델이 특정 기업 소식의 시장 전체 영향을 과대평가한 것일 수 있다.

## 3. 사용자가 먼저 생각할 질문

1. GPT가 틀린 이유가 프롬프트 문제인가, 사람 라벨 기준 문제인가?
2. 간접적인 시장 개선 효과를 긍정으로 볼 범위를 어디까지 허용할 것인가?
3. 해외 시장 뉴스나 특정 기업 뉴스는 국내 전기차 시장 기준에서 어떻게 처리할 것인가?

## 4. 최소 실행 코드

GPT API dev 예측 결과를 기준으로 오분류를 분석한다.

```powershell
uv run python src/analyze_misclassifications.py
```

출력 파일은 다음 위치에 생성된다.

```text
reports/error_analysis_openai_gpt_20260803.csv
reports/error_analysis_openai_gpt_20260803.md
```

## 5. 프롬프트 반복 개선 방식

현재 GPT API 스크립트는 프롬프트 버전을 선택할 수 있다.

기존 프롬프트는 `v1`이다.

```powershell
uv run python src/openai_gpt_classifier.py --run --split dev --limit 0 --prompt-version v1 --max-krw 10000
```

오분류 검토를 반영한 개선 프롬프트는 `v2`다.

```powershell
uv run python src/openai_gpt_classifier.py --run --split dev --limit 0 --prompt-version v2 --max-krw 10000
```

`v2`는 다음 내용을 더 명확히 한다.

- 직접적인 등록대수 증가가 없어도 구매·이용 조건 개선이면 긍정 후보로 본다.
- 안전 대응 강화, 배터리 안전성 개선, 충전 인프라 개선, 라인업 확대, 구매·정비 지원 강화는 긍정 후보로 본다.
- 해외 시장, 특정 기업 주가, 연구 초기 단계 뉴스는 국내 적용 근거가 없으면 중립으로 본다.

## 6. 결과 해석 방법

프롬프트를 바꾼 뒤에는 Accuracy만 비교하지 않는다.

다음을 함께 비교한다.

- Macro-F1
- 클래스별 Precision
- 클래스별 Recall
- 클래스별 F1
- 혼동행렬
- 분류 실패 수

프롬프트 v2가 긍정 Recall을 높이더라도,
중립 기사를 긍정으로 많이 오판하면 좋은 개선이 아닐 수 있다.

## 7. 오류, 편향, 데이터 누수 가능성

dev 데이터의 오류를 보고 프롬프트를 고치는 것은 허용된다.

하지만 final_test 데이터를 보고 프롬프트를 고치면 데이터 누수다.
최종 테스트 데이터는 마지막 평가 때만 사용한다.

또한 현재 dev 데이터는 긍정 라벨이 많다.
프롬프트를 dev 데이터에 지나치게 맞추면 긍정으로 과하게 분류하는 모델이 될 수 있다.

## 8. 완료 조건

9단계는 다음 조건을 만족하면 완료된다.

- GPT API 오분류 사례를 추출했다.
- 오류 유형을 분류했다.
- 프롬프트 개선 방향을 문서화했다.
- 개선 프롬프트를 코드에서 선택할 수 있다.
- final_test 데이터는 프롬프트 개선에 사용하지 않았다.
