# 데이터 디렉터리

이 디렉터리는 데이터 처리 단계에 따라 파일을 분리합니다.

- `raw/`: 네이버 API 원본 JSON과 수집 CSV. 재생성 가능하므로 Git에서 제외합니다.
- `processed/`: HTML 제거, 날짜 통일, 중복 제거 결과. Git에서 제외합니다.
- `labels/`: 사람이 작성한 정답 라벨 데이터입니다.
- `predictions/`: 모델별 예측 결과입니다.
- `cache/`: 재실행 캐시가 필요할 때 사용하며 Git에서 제외합니다.

뉴스 제목과 요약문은 네이버 뉴스 검색 API에서 수집한 공개 검색 결과입니다.
데이터를 재배포하거나 확장해 공개하기 전에는 API 이용약관과 원문 저작권을 확인해야 합니다.
